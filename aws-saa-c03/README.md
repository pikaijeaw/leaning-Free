# AWS Solutions Architect Associate (SAA-C03): audio class

A beginner audio class, about 2 minutes per lesson, built from 37 free web pages and following the SAA-C03 exam guide's topics. Each lesson folder in `class/` has the audio (`.mp3`), a one-screen card (`card.md`), and the script.

- `class/lesson-plan.md`: the 12 lessons, the arcs, and where sources disagree
- `research/agreement-map.md`: which ideas the sources agree on, with links
- `sources.json`: the reading list

Source pages themselves are not included; every card links to the original.
