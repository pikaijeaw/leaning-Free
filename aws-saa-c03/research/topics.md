# Topics: AWS Certified Solutions Architect Associate (SAA-C03), beginner

Syllabus shaped by the official SAA-C03 exam guide (4 domains: secure, resilient, high-performing, cost-optimized) and the section order commonly used by the Udemy "Ultimate AWS Certified Solutions Architect Associate" course.

- T01 Exam format and how people study for it (domains, scoring, practice tests, hands-on)
- T02 Global infrastructure: Regions, Availability Zones, edge locations; choosing a Region
- T03 IAM: users, groups, roles, policies, least privilege, MFA, root account
- T04 EC2: instance basics, security groups, purchasing options (On-Demand, Reserved, Savings Plans, Spot)
- T05 Block and file storage: EBS, instance store, EFS, snapshots
- T06 Elastic Load Balancing and Auto Scaling: ALB/NLB, health checks, scaling policies
- T07 Relational databases and caching: RDS, Multi-AZ vs read replicas, Aurora, ElastiCache
- T08 Route 53: DNS, record types, routing policies, health checks
- T09 Amazon S3: buckets, storage classes, lifecycle, versioning, replication, bucket security
- T10 Edge delivery: CloudFront, Global Accelerator
- T11 Decoupling: SQS, SNS, fan-out, Kinesis, EventBridge
- T12 Serverless: Lambda, DynamoDB, API Gateway
- T13 VPC networking: CIDR, subnets, route tables, IGW, NAT gateway, SG vs NACL, endpoints, peering
- T14 Security services and encryption: KMS, Secrets Manager, Shield, WAF
- T15 Monitoring and auditing: CloudWatch, CloudTrail, Config
- T16 High availability and disaster recovery: Multi-AZ, backup/restore, pilot light, warm standby, RTO/RPO
- T17 Well-Architected Framework and cost optimization
- T18 Containers: ECS, EKS, Fargate, ECR
