# Topics: ISC2 Certified in Cybersecurity (CC), beginner

Shaped by the ISC2 CC exam outline effective 1 September 2026 (five domains: Security Principles 24%, Security Governance 17.3%, IAM Concepts 20%, Networking and Cloud Security Concepts 21.3%, Security Operations and Incident Response 17.3%; AI topics across all domains). The official outline page and PDF could not be saved; weights come from secondary pages that quote it.

- T01 Exam format, the 2026 outline change, how people prepare, cost and value
- T02 CIA triad and core principles (authenticity, non-repudiation, privacy)
- T03 Risk management: likelihood and impact, risk treatment (avoid, mitigate, transfer, accept)
- T04 Security controls: physical, technical, administrative; defense in depth
- T05 ISC2 Code of Ethics
- T06 Governance: policies, standards, procedures, guidelines; regulations
- T07 Business continuity and disaster recovery
- T08 Authentication and MFA factors
- T09 Access control models (DAC, MAC, RBAC, ABAC), least privilege, separation of duties
- T10 Networking basics: OSI, TCP/IP, ports and protocols
- T11 Threats and attacks: malware types, phishing, DDoS, man-in-the-middle
- T12 Network defenses: firewalls, segmentation, IDS/IPS
- T13 Cloud: service models, deployment models, shared responsibility
- T14 Cryptography basics: symmetric, asymmetric, hashing
- T15 Data security: classification, data lifecycle, retention, destruction
- T16 Incident response lifecycle (NIST)
- T17 Security operations: logging, monitoring, awareness training, hardening
- T18 AI security risks: data poisoning, prompt injection, AI identities
