# ISC2 Certified in Cybersecurity (CC): audio class

A beginner audio class, about 2 minutes per lesson, built from 37 free web pages and following the CC outline in force since 1 September 2026 (five domains, AI in all of them). Each lesson folder in `class/` has the script and a one-screen card (`card.md`); audio is added once rendered.

- `class/lesson-plan.md`: the 12 lessons, the arcs, and where sources disagree
- `research/agreement-map.md`: which ideas the sources agree on, with links and flags on outdated claims
- `sources.json`: the reading list

Source pages themselves are not included; every card links to the original. Exam facts (price, delivery, outline) change; check ISC2 before booking.
