# RHCSA (EX200): audio class

A beginner audio class, about 2 minutes per lesson, built from 34 free web pages and led by Red Hat's own EX200 objectives (RHEL 10 era). Each lesson folder in `class/` has the script and a one-screen card (`card.md`); audio is added once rendered.

- `class/lesson-plan.md`: the 12 lessons, the arcs, and where sources disagree
- `research/agreement-map.md`: which ideas the sources agree on, with links and flags on outdated claims
- `sources.json`: the reading list

Source pages themselves are not included; every card links to the original.
